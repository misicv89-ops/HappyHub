# Happy Hub Igraonica – sajt (demo)

## Postavljanje na GitHub Pages
1. Napravi novi repozitorijum na GitHub-u (npr. `happyhub`).
2. Ubaci SVE fajlove iz ovog foldera (index.html, support.js, image-slot.js, .nojekyll, folder assets/).
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Za 1–2 minuta sajt je na: https://KORISNIK.github.io/happyhub/

## Fajlovi
- index.html – sajt (desktop + mobilni, responsive)
- pregled.html – desktop i mobilni prikaz jedan pored drugog
- assets/ – slike, logo i video

Napomena: forma za rezervaciju je demo (ne šalje poruke). Video je ~20 MB; za produkciju preporuka je kompresija na 3–5 MB.
